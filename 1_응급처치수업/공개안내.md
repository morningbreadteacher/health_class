# 1차시 · 응급처치 수업

친구를 돕는 꼬마 구조대가 되어 응급처치 방법을 배워 보세요.

[게임 시작하기](https://morningbreadteacher.github.io/health_class/1_%EC%9D%91%EA%B8%89%EC%B2%98%EC%B9%98%EC%88%98%EC%97%85/%EC%88%98%EC%97%85%EC%9E%90%EB%A3%8C/%EC%9D%91%EA%B8%89%EC%B2%98%EC%B9%98%EA%B2%8C%EC%9E%84_%EB%A1%9C%EC%BB%AC%EC%8B%A4%ED%96%89%EC%9A%A9.html)

## 이용 방법

1. 모둠 이름을 입력하고 확인을 누릅니다.
2. 사건을 골라 장비 선택, 순서 맞추기, 퀴즈에 도전합니다.
3. 완료한 사건에는 미션 완료 배지가 표시됩니다.

모둠 이름과 완료 기록은 사용 중인 브라우저에만 저장됩니다. 새로운 모둠 이름을 확인하면 이전 완료 기록이 초기화됩니다.
