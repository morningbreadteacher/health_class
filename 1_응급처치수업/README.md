# 1차시 · 응급처치 수업

초등 보건 수업을 위한 「출동! 꼬마 구조대」 미션 게임입니다.

[온라인 게임 실행](https://morningbreadteacher.github.io/health_class/1_응급처치수업/)

## 학습 내용

찰과상, 코피, 화상, 발목 염좌, 눈에 먼지가 들어간 상황, 벌 쏘임의 6가지 사건을 다룹니다. 장비 선택 → 처치 순서 → 이유 퀴즈 → 도전 상황을 해결합니다. 상처와 화상은 제공받은 교과서 내용을 반영했습니다.

## 파일

- index.html: 게임 본문. 로컬에서도 열 수 있습니다.
- assets/: 사건별 AI 재현 이미지 6장.
- 정답지.txt: 교사용 장비·순서·퀴즈 정답과 해설.
- 응급처치수업.url, 보건수업.url: 온라인 게임으로 연결하는 인터넷 바로가기.
- 보건게임-사진포함.zip: index.html과 assets/를 포함한 배포용 압축파일.
- 이미지-제작안.txt: AI 이미지 제작 내용.

## 운영

모둠 이름 입력 후 확인을 누르면 기존 완료 기록이 초기화됩니다. 완료 배지는 같은 브라우저에 저장되며 교사에게 전송되지 않습니다. 보기 순서는 미션 시작마다 섞이므로 정답지는 정답 내용으로 확인합니다.

현재 버전: 1.5
