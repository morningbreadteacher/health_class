# 1차시 · 응급처치 수업

초등 보건 수업용 「출동! 꼬마 구조대」 미션 게임입니다.

[온라인 게임 실행](https://morningbreadteacher.github.io/health_class/1_%EC%9D%91%EA%B8%89%EC%B2%98%EC%B9%98%EC%88%98%EC%97%85/%EC%88%98%EC%97%85%EC%9E%90%EB%A3%8C/%EC%9D%91%EA%B8%89%EC%B2%98%EC%B9%98%EA%B2%8C%EC%9E%84.html)

## 사용 방법

응급처치수업.url을 더블클릭하면 온라인 게임이 열립니다. 인터넷 없이 실행하려면 수업자료/응급처치게임.html을 여세요.

## 구성

- README.md: 이번 수업 안내.
- 응급처치수업.url: 온라인 게임 인터넷 바로가기 1개.
- 수업자료/응급처치게임.html: 게임 본문.
- 수업자료/assets/: 사건별 AI 재현 이미지 6장.
- 수업자료/정답지.txt: 교사용 장비·순서·퀴즈 정답과 해설.
- 수업자료/이미지-제작안.txt: 이미지 제작 내용.
- 수업자료/보건게임-사진포함.zip: 응급처치게임.html과 assets/를 포함한 배포용 파일.

## 학습 및 운영

찰과상, 코피, 화상, 발목 염좌, 눈의 먼지, 벌 쏘임의 6가지 사건을 다룹니다. 상처와 화상은 제공받은 교과서 내용을 반영했습니다.
모둠 이름 입력 후 확인하면 이전 완료 기록이 초기화됩니다. 모둠 이름과 완료 배지는 브라우저에만 저장되며 교사에게 전송되지 않습니다. 보기 순서는 무작위이므로 정답 내용으로 확인합니다.

현재 버전: 1.6
